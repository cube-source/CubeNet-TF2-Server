# SS Bot Manager

## Overview

SS Bot Manager provides persistent bot identities for CubeNet TF2 servers.

The plugin prevents default TF2 bot naming behavior and replaces it with custom managed profiles.

---

## Source


sourcemod/scripting/ss_botmanager.sp


## Compiled Plugin


sourcemod/plugins/ss_botmanager.smx


---

## Configuration

Bot roster:


sourcemod/configs/ss_bot_roster.cfg


---

## Features

- Persistent bot names
- Custom roster system
- Bot difficulty assignment
- Automatic rename protection
- SQLite support
