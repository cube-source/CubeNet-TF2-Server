# CubeNet TF2 Server Installation Guide

## Overview

This guide covers deploying the CubeNet Team Fortress 2 dedicated server environment.

The project contains:

- Server configuration files
- SourceMod plugins
- Custom bot management systems
- Administrative configurations

---

# Requirements

## Server

Recommended:

- Linux dedicated server
- SteamCMD installation
- Team Fortress 2 Dedicated Server
- MetaMod:Source
- SourceMod

## Hardware

Recommended:

- 4 CPU cores
- 8GB RAM
- 20GB+ storage
